## 全量自动化门槛

发布候选需按《本地开发与运维》的 Compose 命令完成 Ruff、Pyright、后端 pytest、数据库集成测试、ESLint、vue-tsc、Vitest、Prettier、前端构建和 10 项 Playwright。数据库集成测试必须使用隔离测试库或确认当前库中的业务数据可以保留。真实模型 smoke test 为可选项；未提供供应商凭证时，对应行为的自动化证据来自 Fake provider。

## 并发与运行保障证据

- 删除/启动竞态及清理失败重试：`tests/unit/test_hardening.py::test_task_delete_reservation_prevents_a_concurrent_start`、`test_task_delete_preserves_database_record_when_asset_cleanup_fails`。
- outbox 重复投递及锁忙重试：`tests/unit/test_workflow_worker.py::test_stale_duplicate_delivery_is_discarded_after_acquiring_task_lock`、`test_current_delivery_is_retried_when_another_worker_holds_the_lock`、`test_lock_contention_retries_the_current_delivery_without_a_retry_limit`、`test_workflow_celery_tasks_allow_unbounded_lock_contention_retries`、`tests/integration/test_outbox.py::test_new_workflow_event_fences_an_old_duplicate_delivery`。事件 ID 与任务当前事件在 PostgreSQL 同一事务写入；仍有效的事件在锁忙时退避重试，旧事件被丢弃。
- 取消期间的页面/进度写入：`tests/integration/test_slide_repository.py::test_cancelled_task_fences_an_in_flight_slide_batch_and_progress_write`。测试在模型批次等待期间取消任务，再释放批次；状态检查和提交共享任务行锁。
- 租约换主后的旧 Worker 写入：`tests/integration/test_slide_repository.py::test_replaced_worker_fencing_token_blocks_stale_writes` 验证旧代数无法更新进度、页面、状态投影或失败状态；`tests/integration/test_workflow_checkpoint_fencing.py::test_stale_worker_cannot_replace_a_newer_langgraph_checkpoint` 验证旧代 Worker 不能覆盖 LangGraph checkpoint；`tests/integration/test_outbox.py::test_redis_lease_generations_increase_across_worker_takeovers` 验证真实 Redis 原子地产生递增代数。
- Worker 预检依赖故障：`tests/unit/test_workflow_worker.py::test_preflight_dependency_failure_requests_workflow_retry` 覆盖 PostgreSQL 查询、连接池耗尽和 Redis 租约获取故障；暂时不可用状态都会让 Celery 退避重试，不会丢失已发布 outbox 事件。
